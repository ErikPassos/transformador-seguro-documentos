TRANSFORMADOR SEGURO DE DOCUMENTOS - GERACAO DO INSTALADOR

Este pacote contem os arquivos de build. O instalador .exe deve ser compilado no Windows onde esta o projeto Python completo.

1. Copie estes arquivos para a raiz do projeto:
   - TransformadorSeguro.spec
   - instalador.iss
   - gerar_instalador.ps1
   - requirements-desktop.txt

2. Confirme que a raiz tambem contem:
   - interface.py
   - processamento.py
   - validacao.py
   - inspecao.py
   - deteccao_tabelas.py
   - extracao_tabelas.py
   - exportacao_excel.py

3. Instale o Inno Setup 6 no Windows.

4. Abra o PowerShell na pasta do projeto e execute:

   Set-ExecutionPolicy -Scope Process Bypass
   .\gerar_instalador.ps1

5. Arquivos esperados:

   dist\TransformadorSeguro\TransformadorSeguro.exe
   instalador\TransformadorSeguro-Setup-1.0.0.exe

6. Teste primeiro o executavel em dist. Depois teste o instalador em outro computador Windows.

Observacao: PyInstaller nao e compilador cruzado. O executavel Windows deve ser criado no Windows.
